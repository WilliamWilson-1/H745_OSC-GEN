## 实机运行检查

复位启动后，首页默认 RUN 可连续采集和提交画面。通过调试接口向 H745 触摸接收队列注入正常格式的测试消息，检查真实主循环处理路径；旋钮测试使用 TIM3 计数变化，不调用被测调整函数来绕过输入分发。

1. 进入示波器、连续双指缩放至 2 us/div，状态报告配置采样率 2,000,000 Hz。
2. 点击 Fine 后增加一个编码器计数，时基从 2 变为 3 us/div。
3. 点击 Coarse 后增加一个编码器计数，时基从 3 变为 5 us/div。
4. 点击 RUN/HOLD 再返回 Home：`running=0`、`frame_valid=1`，首页保持已有帧。两次独立读数之间采集和刷新计数保持不变。

| ADC 错误 / 启动失败 | 0 / 0 |

## 未覆盖的条件

这些结果不代替手指在实际屏幕上的手感确认，也不证明物理触摸 I2C/UART 全链路已完成所有异常测试。测试消息注入绕过了 F103 与触摸传感器。

本次未主动给外部电路开启 DAC 输出，因此未测量 100 kHz 输出的失真、满幅建立时间、实际频率精度，也未验证 ADC/DAC 同时工作时的总线压力。2 MS/s 为定时器配置值，未用外部基准独立校准。模拟输入带宽、接线负载、长时间运行、极端触摸压力和用户肉眼观察闪烁仍需要进一步实测。
